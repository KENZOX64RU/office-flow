# Office Flow

**Office Flow** — единый интерактивный справочник по офисным приложениям, бизнес-системам, инструментам аналитики, дизайна и повседневной работы за компьютером.

Находите горячие клавиши, изучайте пошаговые инструкции, осваивайте полезные функции и ускоряйте выполнение задач в десятках программ через единый интерфейс.

## Возможности

- **Горячие клавиши** — сочетания клавиш с описанием действий и особенностей платформ.
- **Пошаговые инструкции** — руководства по выполнению повседневных и продвинутых задач.
- **Команды и функции** — справочник по возможностям программ, инструментам и рабочим процессам.
- **Быстрый поиск** — поиск программ, сочетаний клавиш и инструкций.
- **Категории и подкатегории** — удобная навигация по большой базе знаний.
- **Избранное** — сохранение нужных программ, команд и инструкций.
- **Недавно просмотренное** — быстрый возврат к ранее открытым материалам.
- **Различия платформ и версий** — особенности Windows, macOS, веб-приложений и отдельных версий программ, где применимо.
- **Советы и лайфхаки** — практические приёмы для повышения скорости и эффективности работы.
- **Современный интерфейс** — тёмная тема, плавные анимации и адаптивная навигация.

## Каталог программ

Office Flow объединяет справочную информацию по нескольким направлениям.

### Офисные приложения и документы
Microsoft Office, Microsoft 365, LibreOffice, ONLYOFFICE Docs, Google Docs и другие инструменты для работы с документами, таблицами и презентациями.

### Бухгалтерия и учёт
1С:Бухгалтерия предприятия, 1С:Зарплата и управление персоналом, 1С:Управление торговлей, 1С:Документооборот, Контур, СБИС и МойСклад.

### Браузеры и интернет
Google Chrome, Microsoft Edge, Mozilla Firefox, Яндекс Браузер и Opera.

### Почта и коммуникации
Microsoft Outlook, Microsoft Teams, Telegram Desktop и другие инструменты общения и совместной работы.

### PDF и документы
Adobe Acrobat Reader, Adobe Acrobat Pro, PDF-XChange Editor, Foxit PDF Editor и ABBYY FineReader PDF.

### Таблицы и аналитика
Google Sheets, Microsoft Power BI, Tableau, Power Query и Microsoft Power Pivot.

### Управление проектами и задачами
amoCRM, Notion, Trello, Jira Software, Asana и ClickUp.

### Графика и презентации
Google Slides, Figma, Canva, Adobe Photoshop, Adobe Illustrator и другие инструменты визуального контента.

### Системные инструменты Windows
Windows 10, Windows 11, Проводник Windows, Диспетчер задач и другие системные средства.

### IT и администрирование
PowerShell, командная строка CMD, Windows Terminal и инструменты для технической работы.

Каталог развивается: перечень программ и глубина наполнения отдельных разделов могут меняться.

## Для кого

Office Flow предназначен для офисных сотрудников, бухгалтеров, аналитиков, специалистов по продажам, дизайнеров, IT-специалистов, администраторов и всех, кто регулярно работает с компьютерными программами.

## Принципы качества

- Точность горячих клавиш и описаний команд.
- Учёт различий между программами, версиями и платформами.
- Понятные инструкции с последовательными шагами.
- Отсутствие дублирующих и неподтверждённых записей.
- Постоянное расширение и улучшение базы знаний.

## Статус проекта

Office Flow находится в активной разработке. База знаний постепенно расширяется, а функциональность и удобство интерфейса совершенствуются.
